# Security policy

## Supported versions

The latest release of rowgate receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Email **info@thedataguys.org** with the subject line `rowgate security`, a description of the issue and steps to reproduce it. You can also use GitHub's [private vulnerability reporting](https://github.com/DTheDataGuy/rowgate/security/advisories/new).

You will get an acknowledgement within 5 business days.
